# 📚 PrepTrack – Placement Preparation Dashboard

PrepTrack is a responsive web-based **placement preparation dashboard** designed to help students organize and track their placement preparation in one place.

## 🚀 Features

* 📊 **Overall Progress** – View your placement preparation progress.
* ✅ **Task Management** – Add daily tasks and mark them as completed.
* 📚 **Subject Progress** – Track progress in subjects like JavaScript, React, SQL and Aptitude.
* 💼 **Job Applications** – View recently applied companies and application status.
* 🎯 **Upcoming Interviews** – Keep track of upcoming interview dates.
* 🌙 **Dark Mode** – Switch between light and dark themes.
* 📱 **Responsive Design** – Works on desktop, tablet and mobile screens.

## 🛠️ Technologies Used

* **HTML5** – Structure of the dashboard
* **CSS3** – Styling, layout and responsive design
* **JavaScript** – Task management and theme switching

## 💻 How to Run

1. Clone this repository:

```bash
git clone https://github.com/YOUR-USERNAME/PrepTrack.git
```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

   **OR**

   Use the **Live Server** extension in VS Code.

## 🎯 Purpose

The purpose of PrepTrack is to provide students with a simple dashboard for managing their placement preparation, daily tasks, subjects, job applications and interviews.
